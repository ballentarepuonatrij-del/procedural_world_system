# PlanetLab

**Готовые файлы:** [скачать Windows-версию и исходники](https://github.com/ballentarepuonatrij-del/procedural_world_system/tree/main/releases).

Исследуемая процедурная планета на **C++20**, обычное **Win32 desktop-приложение** для Windows 10/11 x64. Основная среда разработки — **Visual Studio 2026**, MSVC v145 и Windows SDK. Внешний игровой движок, загружаемые текстуры и сервер не нужны. Рендеринг использует системный OpenGL 1.1; ядро расчётов не зависит от Win32.

Это работающий начальный симулятор с физическими единицами и проверяемыми расчётами. Он не является полноценной моделью системы Земли: геология, осадки и биомы приближённые; фоновая атмосфера гидростатическая; локальная погода приближённая; океан статический. Границы применимости, формулы и источники перечислены в [SCIENCE.md](docs/SCIENCE.md).

Фактически выполненные проверки и ограничения среды: [VALIDATION.md](docs/VALIDATION.md). В переносимом архиве находятся `PlanetLab.exe` для исследования и `planet_cli.exe` для выборки параметров и экспорта карты.

## Что реализовано

- Сфера радиусом 6371 км. Координаты, высоты и перемещение используют `double`; рендеринг ведётся относительно наблюдателя, без потери точности на планетарных расстояниях.
- Детерминированная генерация по 64-битному seed: континенты, шельф, дно, горные области и мелкие неровности. Трёхмерный шум не имеет шва по долготе. Мягкое смешивание 24 плит устраняет разрывы на их границах.
- Холмы и неровности на масштабах 620, 150, 32 и 9 м; ближняя сетка уплотнена с 8 до 2 м в проекции. Оттенок почвы меняется в пространстве, крутые склоны получают каменистую окраску.
- Процедурные камни, деревья, кустарники и пучки травы. Размещение учитывает годовой климат, осадки, уровень моря и уклон. Объекты сохраняют положение при движении; дальние деревья используют упрощённую геометрию.
- Перемещение от первого лица, мышь, ходьба 2,5 м/с, бег 8 м/с, прыжок, гравитация, столкновения с поверхностью, свободный полёт. Направление движения переносится по сфере и сохраняется при пересечении полюсов.
- Орбитальное движение по уравнению Кеплера, эксцентриситет, осевой наклон, день/ночь, сезоны, полярный день и ночь.
- Стандартная слоистая атмосфера, давление и плотность; упрощённый энергетический климат с тепловой инерцией суши и океана.
- Локальный погодный слой 24 × 24 км: движение ветра, перенос водяного пара и облачной воды, конденсация, испарение и расчёт осадков с контролем баланса воды. Облака движутся и меняют форму; V показывает частицы ветра.
- Восемь переключаемых модулей, обзор планеты и телеметрия поверхности. Стволы и камни препятствуют ходьбе; свободный полёт позволяет пройти через них.
- Три вида ландшафта: естественная поверхность, голубая сетка поверх рельефа и тёмный каркасный вид. Сетка включена по умолчанию; клавиша **G** переключает режимы.
- Консольная выборка научных параметров и экспорт карты в PPM; 48 проверок свойств расчётного ядра.

При включённом океане перемещение по его поверхности — удобство исследования, не физика плавания. Отключение океана открывает дно. Растительность статическая: рост, размножение, животные и интерактивная экосистема ещё не реализованы. Выходные значения осадков и биомов нельзя трактовать как научный прогноз.

## Сборка в Visual Studio 2026

В Visual Studio Installer установите **«Разработка классических приложений на C++»**, **MSVC v145**, **Windows 10 SDK или Windows 11 SDK**, **CMake tools for Windows**. Нужен CMake **4.2 или новее** для генератора `Visual Studio 18 2026`.

Из Developer PowerShell в корне репозитория:

```powershell
cmake --preset vs2026
cmake --build --preset vs2026-release --parallel
ctest --preset vs2026-release
.\build\vs2026\Release\PlanetLab.exe
```

Можно открыть созданное решение `build/vs2026/PlanetLab.sln` или `.slnx` в Visual Studio, выбрать `PlanetLab` стартовым проектом и конфигурацию `Release | x64`. Формат решения зависит от версии CMake/Visual Studio. SDK выбирается генератором из установленных совместимых SDK. Приложение не использует UWP/WinUI.

Установка переносимой сборки в отдельную папку:

```powershell
cmake --install build/vs2026 --config Release --prefix out/PlanetLab
```

Для запуска достаточно `PlanetLab.exe` и стандартных системных DLL Windows. CRT подключается статически. Размер 50 МБ относится к поставляемому приложению, а не к Visual Studio, SDK, отладочным символам или памяти процесса.

## Управление

| Действие | Клавиша |
|---|---|
| Захват мыши / освобождение | Щелчок в окне / Esc |
| Смотреть вокруг | Мышь |
| Движение | WASD |
| Быстрее | Shift |
| Прыжок / подъём в полёте | Пробел |
| Спуск в полёте | Ctrl |
| Ходьба / полёт | F |
| Скорость полёта: 5–20000 м/с | Колесо мыши |
| Поверхность / обзор всей планеты | Tab |
| Сетка → тёмный каркас → обычная поверхность | G |
| Переключить рельеф / океан / атмосферу / климат / биомы | 1 / 2 / 3 / 4 / 5 |
| Переключить камни и растительность | 6 |
| Переключить ветер / облака и влагу | 7 / 8 |
| Показать / скрыть частицы ветра | V |
| Скорость модельного времени | + / − |
| Пауза модельного времени | P |
| Местный солнечный полдень | T |
| Вернуться к месту посадки | Home |
| Следующий seed, новая планета | R |
| Показать/скрыть подсказки | H |
| Закрыть приложение | Крестик окна / Alt+F4 |

Скорость времени меняет астрономию и климат; движение человека всегда идёт в реальном времени. Начальная скорость — 60×. При работающем ветре предел ускорения — 600×; без него — 86400×. Погодная физика использует фиксированный шаг 2 модельные секунды, P останавливает также облака и частицы. T меняет солнечное время, сохраняя уже рассчитанную погоду; R создаёт новую планету и заново инициализирует погоду. День отсчитывается от условного перигелия, не от календарной даты. `T` полезна для возвращения к освещённому виду. В обзоре планеты отображается текущая сторона наблюдателя; для исследования другой области используйте полёт в режиме поверхности.

Решётка повторяет треугольники отображаемого рельефа. Её узлы привязаны к координатам планеты; при движении камеры меняется подробность, а не положение всей решётки. Линии ослабевают вдали и при взгляде почти вдоль поверхности, скрытые склоны не просвечивают. В полёте ячейки становятся крупнее. Каркасный режим использует тёмную поверхность и голубые линии; данные планеты и физика движения от выбора вида не меняются. Клавиша G действует на вид поверхности; обзор планеты сохраняет обычные цвета. Выбранный режим сохраняется при переключении Tab и смене seed в текущем сеансе.

На панели `ON` — работающий модуль; `OFF` — явно отключённый; `WAIT` — включённый пользователем, но ожидающий зависимости. Климат зависит от атмосферы, биомы — от климата, `Surface detail` — от рельефа. Ветер зависит от атмосферы; облака и перенос влаги — от ветра и климата. Выключение 7 приостанавливает оба погодных процесса; 8 позволяет оставить ветер без облаков. Состояние сохраняется при переключении. Без биомов остаются только камни. Клавиша **6** убирает объекты и их столкновения; повторное нажатие возвращает те же объекты. Включение зависимости автоматически восстанавливает ожидающие модули. Сфера, астрономия и навигация остаются базой. Модули встроены в программу: это не загрузка произвольных DLL.

Локальные объекты генерируются вокруг наблюдателя: деревья до 420 м, камни до 220 м, кустарники и трава до 80 м. В полёте выше 100 м трава убирается, выше 1800 м объекты не выводятся. При пересборке местной сетки на границе дальности и при смене уровня подробности возможны появления объектов и изменения силуэта. Полная планета не хранится в памяти; внешние модели и текстуры не загружаются.

Давление, температура, плотность и осадки в HUD относятся к **поверхности под наблюдателем**. `EYE` показывает высоту глаз над условным нулевым уровнем. В вакууме температура воздуха не определена и не показывается. Погодная панель WIND/RH/CLOUD относится к расчётному воздушному слою, высота которого указана в заголовке. RH — относительная влажность, CLOUD — масса облачной воды на квадратный метр. Годовые осадки в нижней панели остаются климатической оценкой.

Погода рассчитывается в локальной области с периодическими границами; при перемещении дальше 5 км область переносится с сохранением перекрывающихся полей и учётом обмена водой. Это первый этап атмосферной динамики: расчёт дождя пока не связан с реками, грунтовой влагой или эрозией. Облака отображаются в режиме поверхности; глобальный погодный покров ещё не рассчитывается.

## Консольные инструменты

```powershell
.\build\vs2026\Release\planet_cli.exe --seed 42 --sample 45 30 --day 79
.\build\vs2026\Release\planet_cli.exe --seed 42 --map world.ppm
.\build\vs2026\Release\PlanetLab.exe --seed 1234
.\build\vs2026\Release\PlanetLab.exe --surface-style wireframe
```

`--sample` принимает широту и долготу в градусах; JSON содержит метры, кельвины, паскали, кг/м³, мм/год, Вт/м². Карта — эквидистантная цилиндрическая проекция 1024×512; цвет обозначает биом, в океане — глубину. PPM открывается, например, GIMP или ImageMagick.

Параметр окна `--surface-style` принимает `natural`, `grid` (по умолчанию) или `wireframe`.
Параметр `--no-detail` запускает приложение с отключённым шестым модулем; в окне его можно включить клавишей 6.

Погодный расчёт и воспроизводимый снимок после 10 модельных минут:

```powershell
.\build\vs2026\Release\planet_cli.exe --seed 42 --sample 14 -15.6 --day 79 --weather 600
.\build\vs2026\Release\PlanetLab.exe --surface-style natural --weather-seconds 600 --paused --wind-tracers --frames 30 --capture weather.ppm --report weather.txt
```

`--weather` в CLI и `--weather-seconds` в окне принимают 0–3600 секунд предварительного расчёта. JSON CLI включает ветер, влажность, облачную воду, осадки и невязку водного баланса. Параметры окна `--no-weather`, `--no-clouds`, `--wind-tracers` и `--paused` соответствуют переключателям 7, 8, V и P. Консольный расчёт работает без графического контекста.

Проверка окна с автоматическим завершением и снимком:

```powershell
.\build\vs2026\Release\PlanetLab.exe --frames 5 --capture surface.ppm --report smoke.txt
.\build\vs2026\Release\PlanetLab.exe --globe --frames 5 --capture globe.ppm --report globe.txt
```

Отчёт `status=ok` записывается после успешного рендеринга. Ошибки OpenGL дают ненулевой код завершения. Снимок читается из реального кадрового буфера.

## Проверка ядра на Linux

Нужны CMake ≥3.25, Ninja и компилятор C++20 (GCC 12+ или Clang 15+).

```sh
cmake --preset linux-core
cmake --build --preset linux-core --parallel 4
ctest --preset linux-core
./build/linux-core/planet_tests all
./build/linux-core/planet_cli --seed 42 --sample 45 30
```

CTest запускает 8 наборов с 48 проверками и отдельный тест CLI. `PLANET_SANITIZERS=ON` включает AddressSanitizer/UBSan в отдельной сборке GCC/Clang. Linux-приложение с графикой не предусмотрено; для проверки Windows UI можно использовать Wine с виртуальным дисплеем. Это дополнение к проверке в настоящей Windows, а не её замена.

## Устройство проекта

| Файл | Назначение |
|---|---|
| `include/planet/math.hpp` | Векторы, сферические координаты, шум, детерминированный hash |
| `include/planet/model.hpp`, `src/model.cpp` | Конфигурация, модули, география, астрономия, атмосфера, климат |
| `include/planet/surface_detail.hpp`, `src/surface_detail.cpp` | Размещение объектов по климату и уклону, формы столкновения |
| `include/planet/navigation.hpp`, `src/navigation.cpp` | Перемещение по сфере, прыжок, столкновения |
| `include/planet/weather.hpp`, `src/weather.cpp` | Погодный слой, проекция ветра, перенос влаги, фазовые переходы и водный баланс |
| `src/win32_main.cpp` | Win32, жизненный цикл окна, ввод, модельное время |
| `src/renderer.cpp` | Местная сетка поверхности, обзор планеты, OpenGL, HUD |
| `src/cli.cpp` | Выборка параметров и карта |
| `tests/core_tests.cpp` | Физические инварианты, контрольные значения, крайние случаи |

Новую подсистему следует добавлять в ядро с явными зависимостями и единицами измерения. Рендерер должен только отображать её состояние. Ближайшие крупные этапы научного развития: водосборы и эрозия с сохранением массы, связь осадков с поверхностной водой, трёхмерная атмосферная динамика, динамические океан/лёд, затем почва и экосистема. Для этих моделей потребуются отдельные сетки, шаги интегрирования и независимая валидация.
