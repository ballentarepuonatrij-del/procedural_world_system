# Проверка сборки 0.1.0

Проверено 2 ноября 2026 года в облачной среде Debian 13 x86_64.

| Проверка | Результат |
|---|---|
| GCC 14.2, C++20, Release | Ядро, CLI и тесты собраны без предупреждений |
| CTest на Linux | 7/7 запусков: 6 наборов с 31 проверкой и контракт CLI |
| AddressSanitizer, LeakSanitizer, UBSan | Все наборы ядра прошли; ошибок памяти и неопределённого поведения не обнаружено в этих сценариях |
| MinGW-w64 GCC 14, Windows x64, Release | `PlanetLab.exe`, `planet_cli.exe`, `planet_tests.exe` успешно собраны |
| Windows-версия расчётного ядра под Wine 10 | 31/31 проверка прошла |
| Окно Win32/OpenGL под Wine + Xvfb | Поверхность и обзор планеты отрисованы, `status=ok`, ошибок OpenGL не зарегистрировано |
| Ввод в окно через XTest | Захват мыши, изменение взгляда, полёт и горизонтальное/вертикальное движение подтверждены отчётом приложения |
| Отключение атмосферы | В кадре климат и биомы показывают `WAIT`, атмосфера — `OFF` |
| Отключение всех пяти модулей | 600 кадров, движение продолжилось, базовая сфера отображается, все переключатели в отчёте равны 0 |
| Новый профиль Wine | Запуск без ручного редактирования профиля, `status=ok`, 4 кадра |
| Повторный сценарий настройки среды | Выполнен; существующие зависимости и результаты сборки переиспользованы |

Графические проверки выполнялись программным OpenGL `llvmpipe (LLVM 19.1.7, 256 bits)`. Это подтверждает создание настоящего Win32-окна, обработку ввода и отрисовку кадрового буфера. Проверка не заменяет запуск на Windows 10/11 с драйверами реального GPU.

**Нативная сборка MSVC v145 в Visual Studio 2026 и запуск на настоящей Windows здесь не выполнялись.** Для них подготовлены CMake-пресет и команды в README. После получения Windows-машины следует выполнить `cmake --preset vs2026`, сборку Release, CTest и оба графических smoke-запуска.

Проверки памяти потребовали разрешённого расширенного режима выполнения: обычная песочница не позволяет LeakSanitizer использовать ptrace. Проверки не отключались. При первичной инициализации 64-битного Wine возможно сообщение о ненайденном 32-битном `rundll32.exe`; выбранный 64-битный сценарий при этом проверен отдельно по коду завершения, отчёту и изображению.

Результаты относятся к текущей машине и исходникам версии 0.1.0. Конфигурация `install_script` и `start_skill` сохранена в черновике облачной среды; публикация и восстановление в новой облачной задаче ещё не проверялись.
